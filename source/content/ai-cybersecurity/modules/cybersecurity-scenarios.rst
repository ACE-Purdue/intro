Cybersecurity Scenarios and Visualizations
==========================================

Apply the ML concepts from the previous module in realistic cybersecurity use-cases using a visually-rich, game-based simulation environment.

Scenario Modules:
------------------
**1. Intrusion and Malware Detection**
- **Datasets**: `CIC-IDS2017 <https://www.unb.ca/cic/datasets/ids-2017.html>`_, `MalMem-2022 <https://www.unb.ca/cic/datasets/malmem-2022.html>`_, `DoHBrw-2020`
- **Techniques**: Feature engineering, model training (CNNs, LSTMs), anomaly detection.
- **Visualization**: 2D and 3D plots using Minecraft entities and t-SNE mappings.

**2. DDoS Attack Mitigation via DRL**
- **Dataset**: `CIC-DDoS2019 <https://www.unb.ca/cic/datasets/ddos-2019.html>`_
- **Method**: Train RL agents to identify and respond to multi-source attacks.
- **Feedback**: Real-time attack geography and performance reward indicators.

Key Takeaways:
---------------
- Learn to interpret cyber threat patterns from data.
- Deploy models within interactive defense environments.
- Use visual aids to demystify complex behavior in adversarial scenarios.
