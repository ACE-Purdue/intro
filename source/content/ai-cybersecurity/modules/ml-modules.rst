ML Modules in the Immersive Environment
=======================================

This module explores how complex AI/ML models are constructed, trained, and visualized through a **Minecraft-based immersive simulation environment**. The goal is to make the abstract components of deep learning both tangible and interactive.

Core Learning Areas:
---------------------
- **Logistic Regression**: Learners build interpretable models by placing blocks representing feature weights and observe dynamic decision boundaries.
- **Fully Connected Neural Networks (FCNNs)**: Parameter tuning via control panels linked to in-game block networks.
- **Convolutional Neural Networks (CNNs)**: Students visualize feature maps, convolution filters, and layer-wise transformations.
- **Recurrent Neural Networks (LSTMs)**: Time-series predictions are explored through animations of gate activations and hidden states.
- **Autoencoders & GANs**:
  - Use Minecraft to encode/decode patterns.
  - Visualize latent space traversal and adversarial image generation.
- **Deep Reinforcement Learning (DRL)**:
  - Applied in a **self-driving car simulation** within Minecraft.
  - Trained using imitation learning and environment feedback via Flask APIs.

Learning Outcomes:
-------------------
- Grasp core ML models by manipulating physical representations.
- Receive real-time feedback to improve model comprehension.
- Develop a concrete mental model of abstract algorithms through guided challenges.
