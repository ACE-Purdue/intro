Machine Learning for Security
==============================

Focusing on ML's role in cybersecurity, this module examines how data-driven models can detect anomalies, mitigate attacks, and adapt to adversarial behavior.

**Learning Outcomes:**
- Train classifiers on intrusion and malware datasets.
- Evaluate robustness against evasion and poisoning.

**Hands-on:** Use of CIC-IDS2017 and MalMem-2022 datasets with model benchmarking.
