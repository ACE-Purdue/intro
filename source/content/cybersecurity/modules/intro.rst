Cybersecurity
=============

This module provides foundational and advanced cybersecurity training tailored to CI (CyberInfrastructure) environments. Topics include secure system design, threat modeling, incident response, and ethical hacking.

**Learning Outcomes:**
- Understand core principles of cybersecurity.
- Apply defensive security techniques to real-world scenarios.
- Recognize risks specific to cyberinfrastructure systems.

**Hands-on:** Labs for intrusion detection, network forensics, and adversarial testing.
